# PCOS 90 Days — V1.0

一个移动端优先的 PCOS 90 天生活方式追踪网页。

## V1.0
- 90 天 / 12 周 Dashboard
- 起始体重、目标体重、7 日均重、腰围
- 每日饮食：按“实际吃掉的量”记录
- 每日运动：爬坡 / 力量 / 步行
- 身体状态：出血、头痛、恶心、便秘、小腿酸痛等
- 优思明 21 天服药 + 7 天停药周期显示
- 本周运动分钟、力量次数、饮食记录、服药记录
- 最近 14 次体重趋势图
- localStorage 本机保存
- JSON 数据备份导出

## 使用
将 `index.html`、`style.css`、`app.js` 上传到 GitHub 仓库根目录，然后开启 GitHub Pages 即可。

首次打开后可在右上角设置：
- 计划开始日期（默认 2026-09-23）
- 起始体重（默认 76.6 kg）
- 阶段目标（默认 73.0 kg）
- 优思明时间（默认 22:00）
- 腰围

> 本网页用于个人记录，不替代医生的诊疗建议。
