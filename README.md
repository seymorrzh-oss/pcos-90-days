# PCOS 90 Days — V1.3.5

## 本版更新

- TODAY 新增睡眠：按日期、小时、分钟记录，分钟限制为 0–59；支持当天记录、历史补记、修改和长按删除。
- TODAY 新增「今日分析」：根据设备本机时间在 21:00 自动开放，无需刷新；有多少数据就分析多少，支持饮食、运动、体重和睡眠，生成后可按最新记录重新分析。
- 今日分析只使用本地规则，不需要 API、API Key 或后端服务。
- 优思明继续保持设备本机时间 22:00 开放，并保留 21 天服药 + 7 天停药以及历史补记。
- 永久数据键仍为 `pcos90-data`；旧数据库缺少 `sleeps`、`dailyAnalyses`、`deleted` 时会自动补为空数组，不覆盖原有数据。
- 旧版 localStorage 迁移只执行一次；完成后只读取 `pcos90-data`，旧 key 仅作为被动副本保留。
- 删除记录会保存稳定 fingerprint tombstone，并一次删除所有相同副本；旧版迁移和 JSON 合并不会恢复已删除记录。用户主动新建同一条记录时会解除对应 tombstone。
- 长按约 650ms 删除，触摸移动会取消，避免滚动误删；屏蔽浏览器长按菜单并保留二次确认。
- JSON 导入继续采用合并模式，并尊重 tombstone。
- 食物解析保留原有食物与实际摄入描述，支持 `串`、`颗`、中文数量和 `×2 / x2`。
- 新增鲜肉皮蛋馄饨、皮蛋鲜肉馄饨、鲜肉馄饨、电烤鸡心、烤鸡心、鸡心串的按单位估算。

## 数据安全

覆盖这 4 个静态文件不会主动清空浏览器数据。不要清除浏览器的网站数据；换浏览器或设备前请先导出 JSON 备份。

永久存储 key：`pcos90-data`
