# PCOS 90 Days — V1.3.1

## 本版重点
- 新增「补记」：体重、饮食、运动、身体状态、优思明历史记录都可以选择过去日期。
- 当天优思明仍严格按设备本机时间：22:00 前按钮置灰，22:00 后开放。
- 修复版本升级数据问题：正式存储 key 固定为 `pcos90-data`，以后版本不得再跟随版本号修改。
- 首次启动会尝试扫描并合并常见 V1.0 / V1.1 / V1.2 localStorage key，尽量找回旧记录。
- 增加 JSON 导出备份 / 导入合并恢复。
- 扩充中国日常饮食与快餐本地估算：水煮蛋、拿铁/牛奶、牛肉刀削面、牛肉面、馄饨、鸡心、池奈炸鸡块咖喱蛋包饭，以及麦当劳/KFC 常见汉堡和小吃等。
- 支持 ml / g / 个 / 块 / 碗 / 杯 / 根 / 份，以及「没喝」「未吃」「只吃3个」「剩1/4」等描述。
- 品牌餐品没有可靠精确营养值时只给区间估算，不冒充官方精确值。

## 覆盖 GitHub
将以下 4 个文件直接覆盖仓库原文件：
- `index.html`
- `style.css`
- `app.js`
- `README.md`

只要 GitHub Pages 的域名和路径没有改变、浏览器网站数据没有被清除，覆盖代码本身不会清空 `localStorage`。

## 建议
更新前如果旧版仍能打开并看到记录，先不要清浏览器缓存/网站数据。V1.3 第一次运行后查看首页「数据安全」区域是否提示检测到旧版本数据，并立即导出一份 JSON 备份。
